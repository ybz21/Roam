多机只加三样东西

现有页面一个像素都不改。工作台、会话、文件、浏览器、手机镜像、Git、终端—— 它们照今天的样子，只是数据来自「当前那台机器」。页面里也不写机器名： 轨是常驻的，它一直在屏幕上，页面再写一遍是把同一件事说七遍。

多机新增的只有三样：① 侧栏底座那枚切换器（全站唯一的入口）· ② 一个新页面 机器 · ③ 设置里一个新分页 多机。手机上第 ① 样落在底栏最后一格。

① 侧栏底座的切换器 —— 全站唯一的入口

它不是新加的按钮：今天那里本来就有一枚「当前设备」（主机图标 + 名字，点开是设置/关于/ 主题/退出）。多机后它终于有了名字——方章 + 机器名 + 状态点，菜单顶上多一段机器列表。 单机时它和今天逐像素一致。

可以点这是活的：点方章展开，切一台看看
四种状态

② 新页面：机器

连了中心才出现在导航「工具」组里；单机时这一项不存在。卡片墙用项目页同一套构件。

③ 设置里新增一个分页：多机

角色二选一（这台机器 / 中心）、接入中心的表单、以及「怎么访问这台机器」。 完整设计见 settings.html—— 那份还讲了初次安装时怎么问和后续改模式各会发生什么。

④ 手机：那一处落在底栏最后一格

手机没有侧栏，就让「更多」那一格的图标变成机器方章——接管，不是新增一格。 #186 之后底栏是 4 格 + 更多、特意留白没补人（390 宽下每格从 65 涨到 78）， 新增一格等于把这个收益吐回去。点开第一段就是切换列表；单机时它退回原来的「⋯ 更多」。
