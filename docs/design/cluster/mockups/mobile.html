手机端：不加一层壳

「我在哪台机器」只由一个地方回答，切换也在同一个地方。桌面上那是侧栏底座； 手机上没有侧栏，于是那个位置是底栏最后一格——图标直接换成机器方章， 常驻可见，点开就是切换列表（中心也在里面）。

页面里一律不写机器名。轨/底栏本来就一直在屏幕上，页面再写一遍是把同一件事说七遍， 用户还得判断这两处是不是一回事。误操作的防线不靠这种被动提示——靠动作发生时 把机器名写进确认框（「在 云 GPU 机 上删除 3 个文件？」），那才是真拦得住的地方。 不新增顶栏：13/17 号设计特意拆掉过它，竖向空间是这块屏上最贵的资源。

底栏那一格：占用的是「更多」，不是新加一格

#186 把概览并进项目页之后，底栏是 4 格 + 更多，特意留白没补人—— 390 宽下每格从 65 涨到 78，相邻图标终于有了像样的间隙。所以机器这件事 不新增一格，而是接管「更多」那一格：图标换成方章，点开的面板第一段是切换列表， 工具和账户接在下面。格数不变，间隙不变，入口仍然只有一个。

单机时它退回原来的「⋯ 更多」——没连中心就当多机不存在，这条对每一个多机元素都成立。
