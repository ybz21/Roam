8. 重开（restore），不是自动恢复

sessions 存了 home_dir / worktree_dir / agent / label / spawn_cmd / spawn_env，足够把壳原样重建。

  • 手动重开：会话列表 / 项目详情页里，dead 会话行末给一个「重开」动作 → POST /sessions/:id/restore → 走现有 ttmux new --json 建新会话（新 id）， restored_from 指向旧行，归属与 label 照抄。旧行保持 dead，不复活。 重开的是壳；agent 的上下文由 agent 自己的 resume 机制负责，我们不假装能接上。
  • 开机恢复：设置页三档 —— 关（默认）/ 仅置顶会话 / 全部。 默认关的理由写在设置项说明里。
  • 恢复哪些：只考虑 died_reason='host-restart' 的行，且按项目去重上限（每项目 ≤3）， 免得一次重启拉起几十个 pane 把机器再压死一次。

8.1 对话（agent transcript）怎么接回来

Claude Code 的对话存在 ~/.claude/projects/<cwd-slug>/<uuid>.jsonl， 与 tmux 无关，重启一段不丢（本机 1.1GB / 166 段）。缺的只是「Roam 不认识它」。 补上一列即可：会话表记下 agent_session_uuid，重开时 claude --resume <uuid>，界面上就能从「已结束的会话」直接接回原对话。

这是把 ①台账 → ③重开 真正闭环的一步：没有它，重开只能给你一个空壳； 有了它，重开等于把那天下午的活原样接着干。
