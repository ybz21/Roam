验收（本机实测）

$ ttmux new --json "落盘验证" --dir /home/ai/codes/ttmux
$ sqlite3 meta.db "select id,created_by,status,initial_cwd from sessions where id='…'"
2026-0812-1813-000m | new | live | /home/ai/codes/ttmux      # 台账有行
$ ls -l ~/.roam/logs/2026-0812-1813-000m.log
-rw-rw-r-- 139 …                                              # 日志有内容
$ ttmux kill … --yes && sqlite3 meta.db "select status,died_reason from sessions where id='…'"
dead | killed                                                # 软删，行还在

$ python3 scripts/dev/rebuild-session-history.py --write
残骸 150 个会话 → 已写入                                       # 历史从 0 条恢复到 150 条
按月分布：2026-05 → 9 · 06 → 88 · 07 → 51 · 08 → 2            # 时间轴对得上
M1 之后仍然存在的缺口（M2/M3 收）：同名会话复用会顶掉上一条历史（_ttmux-* 单例、 固定名插件会话）——需要 session_runs 把「一个会话的多次生命」拆开； 项目台账仍在 projects.json，没有事务；对话 uuid 还没记进表，重开只能给空壳。
