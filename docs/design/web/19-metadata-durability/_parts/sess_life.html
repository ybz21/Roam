6. 会话生命周期（ttmux 层）：软删，不硬删

Reconcile(alive, epoch)
  对每行 status='live'：
    命中活会话                    → 刷新 label / tmux_id / tmux_epoch
    未命中，且 tmux_epoch = 当前   → status='dead', died_reason='killed'
    未命中，且 tmux_epoch ≠ 当前   → status='dead', died_reason='host-restart'
  对每行 status='dead' 且会话名又活了：
                                  → 复活成一行干净的 live 记录（不继承旧来历）
  tmux 盲态                        → 一行都不动

一行都不 DELETE。清理另起一条低频路径：status='dead' ∧ died_at 早于保留期（默认 90 天）
∧ 不属于任何未收尾的 worktree/竞赛/蜂群 → 删除，并连带删 logs/<id>.log。
条数上限默认 5000。
