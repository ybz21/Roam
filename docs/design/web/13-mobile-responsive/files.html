PAGE 03 · FILES

先找文件，再进入沉浸预览

一级页聚焦位置与最近文件；打开文件后使用全屏二级页，预览、源码、分享与 Agent 操作都围绕当前文件展开。

01 · FIND

搜索是第一操作

标题下方固定搜索，支持文件名和路径；最近文件让高频回访无需逐层钻目录。

02 · LOCATION

位置和文件分开表达

“当前项目 / 最近位置 / 收藏”是导航，“文件卡”是内容，避免把路径层级和最近列表混在一起。

03 · PREVIEW

详情占满整屏

手机不保留树栏。打开后标题栏只保留返回、文件名和更多，正文得到最大阅读宽度。
