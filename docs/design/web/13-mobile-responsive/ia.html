二、分工：三个不同的维度

三页要成立，得各自回答一个别人回答不了的问题。同一批会话可以出现在三处，但组织维度必须不同：

页面回答的问题组织维度形态
概览现在该动手的是什么时间 / 紧急度 行动卡（要你动手的）＋ 最近会话（跨项目会话流，按最近活动倒序，排除已进行动卡的）
项目某个仓库里有什么空间 / 归属 项目卡网格，卡内列该项目的会话（会话隶属项目，这是卡片的一部分）
会话所有会话，按条件找全集 / 筛选 平铺列表 ＋ 搜索 ＋ Agent/等待/空闲筛选 ＋ 排序

按这个分工，概览要删掉两样：活跃项目卡网格（那是项目页）和「项目 / 会话」tab（那是把会话页塞进来）。 补上一样：「最近会话」会话流——扁平、跨项目、按最近活动倒序，一行一个。 它和项目页的区别是不按仓库分组，和会话页的区别是不做筛选、只取最近 8 条。
