三、方向簇：它到底是干什么的

用途：在 TUI 里选东西——Claude/Codex 的选项列表、tmux 的 copy-mode、任何用 ↑↓ 选、回车确认的界面。 它存在的全部理由是「让软键盘不必弹出来」：手机键盘一弹吃掉半屏，而选一项其实只需要几次方向键。

现在的问题：① 一个没有标签的十字浮在终端上，谁也看不出是干嘛的； ② 用户反馈点一下会弹键盘——如果属实，它就把自己存在的理由否掉了。

设计答案：首次出现时带一行说明，点一下就消失；并且默认只在检测到 TUI（Claude/Codex 在跑）时出现， 普通 shell 下不显示——普通 shell 里你本来就要打字，方向键的价值低得多。
