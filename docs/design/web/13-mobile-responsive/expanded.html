01 · SHELL

底栏升级成 64px 轨

横向屏幕上纵向像素金贵，底栏 56 + 坞 50 + 安全区要吃掉一百多。轨用的是 14 稿 Activity Bar 的同一套图标，一路到桌面都不换语言。

02 · OVERLAY

终端覆盖，不挤压

并排需要 1112；这一档最宽也才 1279，挤出来的 Canvas 只有 561–735，正是 14 稿要消灭的「页面被压成预览条」。覆盖式反而两边都完整。

03 · CONTINUITY

会话坞没消失，只是搬了家

手机上它在底栏之上，这里在轨底 + 右下角胶囊。离开终端仍然知道有几个会话在跑、几个在等你——这条是三档共同的底线。

04 · CONTAINER

栅格不需要为这一档写新规则

项目卡按 Canvas 宽度做容器查询：轨 64 之后是 841–1215，落在 14 稿的「900–1319 → 2 列」区间。档位是环境，列数是结果。

05 · POINTER

命中区看指针，不看宽度

iPad 横屏 1024 是 coarse，同宽的小笔电是 fine。44px 命中区由 data-pointer 决定，密度偏好由 data-density 决定，两者与档位正交。

06 · KEYBOARD

外接键盘就是桌面键位

iPad 接上妙控键盘后 ⌘K 开搜索、⌘J 开合终端面板、Esc 退出覆盖——与 14 稿同键位，不为平板另发明一套。

导航轨64 px与桌面 Activity Bar 同宽同图标
终端面板480 px覆盖式，不改变 Canvas 布局
常驻分栏下界1280 px低于此值一律覆盖，见 14 稿 §4.2
命中区44 pxcoarse 指针下强制，fine 可降到 32
