SPEC 12会话导航栏重做 · 标签条 / 工具条 说明书 11 · Git 面板 07 · 总览
会话页顶部两行是整个产品里出现频率最高的一块 chrome：开着终端就一直在眼前。 现状是「一排 antd 默认按钮 + emoji」，各控件高度、圆角、图标语言都不统一， 也没有主次分组 —— 看上去像调试面板而不是产品。本篇只重做这两行的视觉与排布， 不改任何交互语义：按钮该做什么还做什么，位置也尽量保持肌肉记忆。
